# Закрытая поставка

Собственный код Telegram Rust остаётся закрытым по решению пользователя от
17.11.2026. Файл [LICENSE](../LICENSE) фиксирует отсутствие публичной лицензии.
В манифестах tg, tg-agent и tg-mtproto указан этот файл через license-file;
MIT/Apache либо иной публичный grant для собственного кода не добавляется.
Имена crates пока рабочие, publish=false сохраняется у трёх библиотек и пяти
изменённых SDK. Публикация, push и передача исходников третьим лицам требуют
отдельного поручения.

Сторонний код сохраняет собственные лицензии и notices. Файлы vendor,
закреплённые upstream-архивы, сведения о происхождении и проверяемые diffs
поставляются вместе с полным source-кандидатом. Закрытый статус обёрток
не заменяет лицензии SDK.

Текущий локальный формат — полный checkout либо проверенный source ZIP с
манифестом; [подключение](INSTALL-SOURCE.md) работает через path или pinned Git
без пользовательских patch-таблиц. Наличие такого архива не предоставляет
публичного разрешения на код. Для проверки нормализованных Cargo-пакетов есть
отдельная локальная репетиция; адрес рабочего частного реестра не предполагается.

Из чистого коммита, с установленным Rust 1.100.0, Git, Python 3.11+ и публичным
Cargo cache из `cargo fetch --locked` без --target:

```powershell
python tools/private_packages.py --toolchain 1.100.0
```

Команда создаёт новый `target/private-packages/<commit>-<id>`: восемь `.crate`,
Git-индекс с загрузками через file:// и evidence с командами, исходным commit,
SHA-256, metadata, независимым consumer.Cargo.lock и runtime-журналом.
Успешный результат имеет `evidence/summary.json` со status=passed.
Автоматической установки компилятора и публикации нет. Временные исходники и
изолированный Cargo home очищаются после завершения; завершённая сборка очищается
через Cargo. При тайм-ауте/аварийном завершении потенциально живые дочерние
процессы требуют отдельной проверки до очистки сохранённого scratch.

Рабочие манифесты не меняются. В staging SDK получают версии `0.12.0-tg.1`
или `3.11.0-tg.1`; внутренние зависимости используют точные версии и явно
выбранный локальный реестр. Cargo.toml.orig исходного SDK сохраняется под именем
Cargo.upstream.toml: исходное имя Cargo резервирует для staging-манифеста.
Состав пакета сохраняет код, генераторы, TL-файлы, лицензии, патчи и примеры/тесты;
служебные .gitignore/.gitattributes остаются в полном source ZIP. Проверка
сопоставляет исходные байты и полные модели целей Cargo до/после нормализации.

Это библиотечные архивы без отдельных Cargo.lock: они создаются с
--exclude-lockfile --no-verify, затем отдельно проверяются сборкой и исполнением
внешнего приложения с собственным lock. Оно берёт все восемь пакетов из реестра,
без path/git/patch/source replacements, и исполняет локальный Bot/MCP/MT fixture.
Cache для обычных зависимостей копируется по хешам исходного lock; приватные
Cargo config/credentials и сервисные переменные окружения не наследуются.

URL реестра привязан к каталогу кандидата, поэтому `.crate` этой репетиции
предназначены для локальной проверки. Для настоящего частного реестра нужны его
явный выбор, повторная упаковка и приёмка с новым URL. Контрольные суммы
подтверждают целостность, но не заменяют доверенный канал поставки. Эти действия
не разрешают передачу кода либо публикацию.

Совместимость, документация, оценка агентов, измерения и проверка безопасности
остаются частью полной цели. Закрытая лицензия их не отменяет.
